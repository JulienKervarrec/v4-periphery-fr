# 8. Sécurité, limites et périmètre

Ce parcours couvre PositionManager, les NFT de position, les actions encodées, les routeurs, les chemins de swap, les deltas, les paiements, les outils de lecture et les adaptateurs de hooks.

Il ne constitue ni un audit ni une validation des déploiements réseau. Le dépôt est encore présenté comme en développement et la licence affichée par GitHub est MIT, tandis que le fichier LICENSE doit rester la référence juridique.

Les risques d’intégration incluent le mauvais réseau, le mauvais PoolManager, les erreurs de décodage, la réentrance, les hooks non prévus, le slippage et la solvabilité du règlement.

La lecture a été effectuée sur le README et les contrats centraux de src/. Aucune installation, compilation, exécution de test ou transaction n’a été effectuée. Consultez la suite de tests du dépôt pour poursuivre.

Retour au [sommaire](README.md).
